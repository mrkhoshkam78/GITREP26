# جستجوی هوشمند (Smart Search)

نسخه **۳.۲** — کاملاً کلاینت‌ساید، بدون نیاز به سرور یا کلید API.

## ساختار پروژه (جداسازی کامل فایل‌ها)

```
smart-search/
├── index.html              # صفحه اصلی (فقط HTML)
├── css/
│   └── style.css           # تمام استایل‌های سفارشی
├── js/
│   └── app.js              # تمام منطق برنامه
├── data/
│   └── keywords.json       # ۶۱۰ کلیدواژه + قوانین گسترش (قابل ارتقا)
├── assets/                 # برای آیکون، لوگو و فایل‌های آینده
└── README.md
```

## ویژگی‌ها

- جستجوی همزمان از ویکی‌پدیا فارسی + انگلیسی + DuckDuckGo
- گسترش هوشمند پرس‌وجو (Query Expansion)
- **۶۱۰ کلیدواژه** دسته‌بندی‌شده در ۱۰ گروه
- انتخاب تعداد نتایج (۳ / ۵ / ۱۰ / ۱۵ / ۲۵)
- فیلتر بر اساس منبع
- تاریخچه جستجو + کش نتایج
- حالت تاریک (Dark Mode)
- لینک مستقیم به جستجوی گوگل
- مناسب آپلود مستقیم روی **GitHub Pages**

## نحوه اجرا

### محلی
از یک سرور محلی ساده استفاده کنید (چون `fetch` برای JSON نیاز به http دارد):

```bash
# با Python
python -m http.server 8000

# یا با VS Code Live Server
```

سپس `http://localhost:8000` را باز کنید.

### GitHub Pages
1. کل پوشه را در ریپازیتوری آپلود کنید.
2. Settings → Pages → Source را روی branch اصلی و مسیر root قرار دهید.
3. سایت آماده است.

## ارتقای کلیدواژه‌ها

فقط فایل زیر را ویرایش کنید:

```
data/keywords.json
```

- گروه جدید اضافه کنید
- کلیدواژه جدید بنویسید
- قوانین `expansions` را گسترش دهید

هیچ نیازی به تغییر `index.html` یا `app.js` نیست.

## نسخه

- **۳.۲** — جداسازی کامل فایل‌ها (HTML/CSS/JS/JSON) + ۶۱۰ کلیدواژه

- ۳.۰ — کنترل تعداد نتایج + کلمات کلیدی گسترده
