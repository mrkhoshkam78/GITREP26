# GITREP26 V7

Premium client-side GitHub project discovery with **README Insight Engine**.

## New in V7
- Fixed search (live GitHub API + suggestions)
- Theme header icon with spin animation
- Connectivity badge: Offline → Online pulse when token authenticated
- Categories expand up to 100 when GitHub token is active
- 3 new categories: Cloud & DevOps, Blockchain & Web3, CLI & Automation
- Subtle floating background shapes
- Hero graphic illustration
- README Insight fixed (`analyzeReadme` pipeline)
- Improved Persian (FA) localization

## Run
```bash
python -m http.server 8080
# http://localhost:8080
```

Open any repository → Details → **Analyze README**.
