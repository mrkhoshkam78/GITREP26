# جستجوی هوشمند v6.0

## تمرکز این نسخه
- **موتور ترکیب عبارت‌محور (۸× قوی‌تر)**: «ساخت سایت» نتایج مرتبط با ساخت وب‌سایت می‌آورد، نه جدا کردن کلمات.
- **رتبه‌بندی هوشمند**: امتیاز Fuzzy عبارت‌محور + بونوس تطابق کامل عبارت + اولویت منبع.
- **۱۰ انیمیشن جدید** + گرافیک غنی‌تر (گرادیان متحرک، شیشه قوی‌تر، درخشش دکمه‌ها، شناوری آیکون).
- بهینه‌سازی متون فارسی رابط کاربری.

## ساختار
```
js/smart-engine.js   → موتور عبارت‌محور
js/search-engines.js → ۶ موتور جستجو
js/app.js            → UI و orchestration
css/style.css        → ۱۰ انیمیشن + گرافیک ارتقا یافته
data/keywords.json   → ۳۲۰۰ کلیدواژه
```
