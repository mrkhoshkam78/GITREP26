# GITREP26 V6

Premium client-side GitHub project discovery with **README Insight Engine**.

## New in V6

- Immersive full-screen landing (search + categories) after load
- Search: up to **13 pages × 8 results**, ranked by stars → forks → activity
- Search progress bar fixed (visible, accurate %)
- Install / PWA button in **Settings**; theme toggle stays in header
- Version label at the bottom of Settings (`GITREP26 v6.0.1`)
- Transparent SVG logo (no background plate)
- Stronger Persian i18n (real-time UI refresh on language switch)
- Expanded EN→FA phrase translator for descriptions & README insight
- README Insight engine quality pass (structured what / who / features / install / usage / commands)

## Run

```bash
python -m http.server 8080
# http://localhost:8080
```

Open any repository → Details → **Analyze README**.
